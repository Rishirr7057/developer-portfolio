# Rishi Kumar Gupta | Developer Portfolio

A static portfolio featuring four client application case studies, professional experience, technical skills, and a downloadable résumé.

## Run locally

From this directory, serve the files over HTTP and open http://localhost:8000.

```sh
python -m http.server 8000
```

The site uses HTML, CSS, and JavaScript with a vendored copy of Three.js. It supports light and dark themes, keyboard navigation, and reduced motion. The deployable static copy is in `dist/`. See [the PRD](PORTFOLIO-PRD.md) for the content and acceptance criteria.
